1Gleichungen lösen

  • Kein Term ohne x → herausheben: x³ − 4x = 0 → x·(x² − 4) = 0 → x = 0, ±2
  • Nur x⁴ und x² → Substitution: u = x², quadratische Gleichung lösen, dann x = ±√u (u negativ → keine Lösung)
  • Sonst → Lösung raten (±1, ±2, …), dann Horner/Polynomdivision
  • Grad n → höchstens n Lösungen
TI-Nspiresolve(x^3-4x=0,x)
factor(x^3-4x)
Nie durch x dividieren, sonst verlierst du x = 0. Bei Substitution: u-Werte sind nicht die Lösung!
