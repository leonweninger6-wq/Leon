Gleichungen & Polynomfunktionen

Hier lernst du, Gleichungen höheren Grades ohne Technologie zu lösen. Das brauchst du später ständig, z. B. bei f′(x) = 0.

1. Grundbegriffe

Definition

(1) Ein Ausdruck der Form anxn + an−1xn−1 + … + a1x + a0 mit n ∈ ℕ, an, …, a0 ∈ ℝ und an ≠ 0 heißt Polynom vom Grad n.

(2) Eine Gleichung anxn + … + a1x + a0 = 0 (mit an ≠ 0) heißt (algebraische) Gleichung vom Grad n.

(3) Eine Stelle x0 heißt Nullstelle von f, wenn f(x0) = 0 ist.

Rotstift

In deiner Mitschrift steht bei der Definition an = 0. Richtig ist an ≠ 0. Sonst würde der höchste Term wegfallen und der Grad wäre gar nicht n.

Der Grad ist die höchste Hochzahl. f(x) = 3x4 − 2x + 7 hat Grad 4, Leitkoeffizient a4 = 3, konstantes Glied a0 = 7.

2. Quadratische Gleichungen (Wiederholung)

Lösungsformeln

x² + px + q = 0  ⇔  x = −p2 ± √( (p2)² − q )

ax² + bx + c = 0  ⇔  x = −b ± √(b² − 4ac)2a

Der Ausdruck unter der Wurzel heißt Diskriminante D. D > 0: zwei Lösungen, D = 0: genau eine Lösung, D < 0: keine reelle Lösung. Beide Formeln stehen auch in der Formelsammlung.

Produkt-Null-Satz

Ein Produkt ist genau dann null, wenn mindestens ein Faktor null ist: A · B = 0 ⇔ A = 0 ∨ B = 0.

Das ist der wichtigste Trick des Kapitels: Bring alles auf eine Seite, mach daraus ein Produkt, setz jeden Faktor null. Die nächsten drei Methoden sind nur verschiedene Wege, ein Produkt zu erzeugen.

3. Methode A: Binomische Formeln

(A + B)² = A² + 2AB + B²    (A − B)² = A² − 2AB + B²    (A + B)(A − B) = A² − B²

Beispiel wie 1.04

  • x² − 6x + 9 = 0 → (x − 3)² = 0 → L = {3}
  • x4 − 81 = 0 → (x² + 9)(x² − 9) = 0 → x² = −9 (keine reelle Lösung) oder x² = 9 → L = {−3, 3}
Rotstift

In einer Mitschrift steht x² − 2x − 1 = (x − 1)(x − 1) und auf einer anderen x² − 2x + 1 = (x − 2)(x + 1). Beides stimmt nicht. Richtig ist x² − 2x + 1 = (x − 1)². Kontrolle: Ausmultiplizieren! (x − 1)² = x² − 2x + 1.

4. Methode B: Herausheben

Wenn kein konstantes Glied da ist, steckt in jedem Term ein x. Heb die kleinste x-Potenz heraus.

Beispiel 1.06 a

  1. x³ − 4x² − 5x = 0
  2. x herausheben: x · (x² − 4x − 5) = 0
  3. Produkt-Null-Satz: x = 0 oder x² − 4x − 5 = 0
  4. Kleine Lösungsformel: x = 2 ± √(4 + 5) = 2 ± 3 → x = 5 oder x = −1
  5. L = {−1, 0, 5}
Rotstift · Lieblingsfehler 1.07

Nie durch x (oder durch eine Klammer mit x) dividieren! Wer x³ − 4x² − 5x = 0 durch x dividiert, verliert die Lösung x = 0. Genauso bei x²(x − 4) = 9(x − 4): nicht durch (x − 4) kürzen, sondern (x − 4) herausheben: (x − 4)(x² − 9) = 0 → L = {−3, 3, 4}.

5. Methode C: Substitution

Bei Gleichungen, in denen nur x4 und x² (oder x6 und x³) vorkommen, ersetzt du die kleinere Potenz durch u. Eine Gleichung ax4 + bx² + c = 0 heißt biquadratisch.

Beispiel 1.12

  1. x4 − x² − 2 = 0. Setze u = x², also x4 = u².
  2. u² − u − 2 = 0 → u = 2 oder u = −1
  3. Rücksubstitution: x² = 2 → x = ±√2; x² = −1 → keine reelle Lösung.
  4. L = {−√2, √2}

Bei x6 − 9x³ + 8 = 0 setzt du u = x³: u² − 9u + 8 = 0 → u = 1 oder u = 8 → x³ = 1 → x = 1; x³ = 8 → x = 2. Achtung: x³ = −8 hätte die Lösung x = −2 (dritte Wurzel geht auch aus negativen Zahlen), x² = −8 hätte keine.

Merke

Die Rücksubstitution nie vergessen! Gefragt ist x, nicht u. Bei u = x² gibt jedes positive u zwei Lösungen (±), jedes negative u keine.

6. Linearfaktoren abspalten (Horner, Polynomdivision)

Satz (Regel von Horner)

Für alle a, b ∈ ℝ und n ∈ ℕ* gilt:

an − bn = (a − b) · (an−1 + an−2·b + … + a·bn−2 + bn−1)

Für n = 2 ist das die 3. binomische Formel, für n = 3: a³ − b³ = (a − b)(a² + ab + b²).

Satz (Abspalten eines Linearfaktors)

Ist f ein Polynom vom Grad n und x0 eine Lösung von f(x) = 0, dann gilt für alle x ∈ ℝ: f(x) = (x − x0) · g(x), wobei g ein Polynom vom Grad n − 1 ist. Den Faktor (x − x0) nennt man Linearfaktor.

So gehst du vor, wenn nichts anderes hilft: Rate eine Lösung (probier 1, −1, 2, −2, … das sind Teiler des konstanten Glieds), dividiere durch (x − x0) und löse die übrig gebliebene quadratische Gleichung.

Beispiel aus deiner Mitschrift

  1. x³ − 2x² − 9x + 18 = 0. Probieren: 2³ − 2·4 − 18 + 18 = 0 ✓, also x0 = 2.
  2. Polynomdivision: (x³ − 2x² − 9x + 18) : (x − 2) = x² − 9
  3. (x − 2)(x² − 9) = 0 → x² = 9 → x = ±3
  4. L = {−3, 2, 3}

(Hier geht's sogar schneller mit Herausheben in Gruppen: x²(x − 2) − 9(x − 2) = (x − 2)(x² − 9).)

Wie geht Polynomdivision nochmal? (Beispiel 1.18)

(x³ + 2x² − 13x + 10) : (x − 1)

  x³ + 2x² − 13x + 10 : (x − 1) = x² + 3x − 10
−(x³ −  x²)              ← x² · (x − 1)
       3x² − 13x
     −(3x² −  3x)        ← 3x · (x − 1)
            −10x + 10
          −(−10x + 10)   ← −10 · (x − 1)
                   0     ← Rest 0: passt!

Dann x² + 3x − 10 = 0 → x = 2 oder x = −5. L = {1, 2, −5}.

Umgekehrt: Kennst du alle Nullstellen, kannst du das Polynom als Produkt schreiben (Linearfaktordarstellung): Nullstellen 2, −3, 5, 0 → f(x) = a · (x − 2)(x + 3)(x − 5) · x. Den Faktor a bestimmt ein weiterer Punkt.

7. Wie viele Lösungen gibt es?

Satz

Eine algebraische Gleichung vom Grad n hat in ℝ höchstens n Lösungen. Eine Polynomfunktion vom Grad n hat höchstens n Nullstellen.

Warum? Jede Lösung x1 spaltet einen Linearfaktor ab, und der Rest hat einen Grad weniger. Nach n Lösungen bleibt an(x − x1)(x − x2)…(x − xn) übrig. Eine weitere Lösung müsste einen dieser Faktoren null machen, ist also schon dabei.

„Eine algebraische Gleichung vom Grad  n  besitzt in ℝ  höchstens  n Lösungen.“ Nicht „genau“: x² + 1 = 0 hat Grad 2, aber keine Lösung.

Entscheidungsbaum: Welche Methode?

  1. Fehlt das konstante Glied? → Herausheben.
  2. Nur zwei Potenzen, eine doppelt so groß wie die andere (x⁴ & x², x⁶ & x³)? → Substitution.
  3. Sieht es aus wie A² ± 2AB + B² oder A² − B²? → binomische Formel.
  4. Kommt dieselbe Klammer auf beiden Seiten vor? → alles auf eine Seite, Klammer herausheben.
  5. Sonst: Lösung raten und Linearfaktor abspalten.
  6. Kontrolle mit dem TI-Nspire: solve(x^3-2x^2-9x+18=0,x) oder factor(x^3-2x^2-9x+18).

Änderungsraten & Limes

Die Grundidee der ganzen Differentialrechnung: Wie schnell ändert sich etwas? Zuerst im Mittel über ein Intervall (Differenzenquotient), dann in einem einzigen Moment (Differentialquotient).

1. Absolute Änderung und Differenzenquotient

Absolute Änderung von f in [a; b]: f(b) − f(a). Das sagt, um wie viel sich etwas geändert hat.

Definition

Sei f: A → ℝ eine reelle Funktion, a, b ∈ A, a ≠ b. Die Zahl

f(b) − f(a)b − a

heißt Differenzenquotient oder mittlere Änderungsrate von f in [a; b].

Geometrisch ist das die Steigung der Sekante, also der Geraden durch (a | f(a)) und (b | f(b)). Im Steigungsdreieck: hinauf durch hinüber.

VorzeichenBedeutung
> 0f steigt im Mittel in [a; b] (f(b) > f(a))
= 0f ist im Mittel gleich geblieben (f(b) = f(a)); die Sekante ist waagrecht
< 0f fällt im Mittel in [a; b] (f(b) < f(a))
Rotstift · SA 2025, Bsp. 2

„Im Mittel fallend“ heißt nicht, dass f überall fällt! Aus f(b) − f(a)b − a < 0 folgt nur: Sekante hat negative Steigung, mittlere Änderungsrate ist negativ, f(b) < f(a). Über die Tangenten (momentane Änderungsrate) an einzelnen Stellen weißt du nichts. Dazwischen kann f auch kurz steigen.

Satz (mit Beweis)

Der Differenzenquotient einer linearen Funktion f(x) = k·x + d ist in jedem Intervall gleich der Steigung k.

Beweis: f(b) − f(a)b − a = (kb + d) − (ka + d)b − a = kb − kab − a = k(b − a)b − a = k ∎

Beispiel 2.02 a · 14.9.

f(x) = 3x², Intervall [1; 5]: f(5) − f(1)5 − 1 = 75 − 34 = 724 = 18.

Beispiel im Kontext 2.51 · 25.9.

Energie E(t) = 5000·t² (in Joule, t in Sekunden).

  • Absolute Zunahme in [0; 5]: E(5) − E(0) = 125 000 J; in [5; 10]: 500 000 − 125 000 = 375 000 J.
  • Mittlere Zunahme in [0; 5]: 125 000 / 5 = 25 000 J/s; in [5; 10]: 375 000 / 5 = 75 000 J/s.

Beachte die Einheit: Einheit von E durch Einheit von t, also J/s.

Mittlere Geschwindigkeit

Definition

Bewegt sich ein Körper nach der Zeit-Ort-Funktion s: t ↦ s(t), dann ist die mittlere Geschwindigkeit im Zeitintervall [t1; t2]:

v(t1; t2) = s(t2) − s(t1)t2 − t1

Die Geschwindigkeit zum Zeitpunkt t (Momentangeschwindigkeit) ist der Grenzwert v(t) = limz→t v(t; z).

2. Vom Differenzen- zum Differentialquotienten

Lass das Intervall immer kleiner werden: z rückt immer näher an x heran. Die Sekante dreht sich dabei und wird zur Tangente. Probier es aus:

Definition

Der Grenzwert

f′(x) = limz→x f(z) − f(x)z − x = limh→0 f(x + h) − f(x)h

heißt Differentialquotient von f an der Stelle x (auch: momentane Änderungsrate, Ableitung an der Stelle x).

Definition (Tangente)

(1) Die Gerade durch den Punkt (x | f(x)) mit der Steigung f′(x) heißt Tangente von f an der Stelle x. (2) Die Steigung f′(x) der Tangente heißt auch Steigung der Funktion f an der Stelle x.

Bei „Kreuze den Term an, der die momentane Änderungsrate an der Stelle x₀ angibt“ ist nur limh→0 f(x₀ + h) − f(x₀)h richtig. Fallen: + statt − im Zähler, z → 0 statt z → x₀, Δx/Δy (verkehrt herum), Grenzwert mit falscher Variable.

3. Den Limes von Hand berechnen

Das muss sitzen: Laut Stoffumfang für f(x) = a·x² und f(x) = a·x. Bei der SA 2025 gab es für h′(x) = 5,8x 0 Punkte, weil die Zwischenschritte fehlten. Das Ergebnis allein zählt nicht!

Das Rezept (z-Form)
  1. Differenzenquotient hinschreiben: f(z) − f(x)z − x
  2. f(z) und f(x) einsetzen.
  3. Im Zähler (z − x) herausheben. Fast immer mit der 3. binomischen Formel z² − x² = (z − x)(z + x).
  4. (z − x) kürzen. Das ist erlaubt, weil z ≠ x ist (z kommt x nur beliebig nahe).
  5. Jetzt erst z = x einsetzen (Limes bilden).

Vorzeigelösung: f(x) = a·x² genau so hinschreiben

f′(x) = limz→x f(z) − f(x)z − x = limz→x a·z² − a·x²z − x = limz→x a·(z² − x²)z − x
= limz→x a·(z − x)(z + x)z − x = limz→x a·(z + x) = a·(x + x) = 2a·x

Beispiel SA 2025: h(x) = 2,9x² → h′(x) = 2 · 2,9 · x = 5,8x, aber eben mit dieser Kette.

Dieselbe Rechnung in der h-Form

f′(x) = limh→0 a(x + h)² − ax²h = limh→0 a(x² + 2xh + h²) − ax²h = limh→0 a(2xh + h²)h
= limh→0 a·h·(2x + h)h = limh→0 a(2x + h) = 2a·x

f(x) = a·x (und der Sonderfall f(x) = c)

f′(x) = limz→x a·z − a·xz − x = limz→x a·(z − x)z − x = limz→x a = a

f(x) = c:   f′(x) = limz→x c − cz − x = limz→x 0 = 0

Schwerer: mit Klammer 2.14 · 17.9.

Wasser im Behälter: V(t) = (10 − t)² (Liter, t in s, 0 ≤ t ≤ 10).

3. Tangente & Steigungswinkel

Satz

Ist k die Steigung und α der Steigungswinkel der Tangente an der Stelle x, so gilt:

f′(x) = k = tan(α)

Rezept: Tangentengleichung an der Stelle p
  1. Punkt: T = (p | f(p))
  2. Steigung: k = f′(p)
  3. In y = k·x + d einsetzen: f(p) = k·p + d → d ausrechnen
  4. Antwort: t: y = k·x + d

Kurzformel (geht auch): t: y = f′(p)·(x − p) + f(p). TI-Nspire: tangentLine(f(x),x,p).

Beispiel Mitschrift

  1. f(2) = 4 − 4 + 10 = 10 → T = (2 | 10)
  2. f′(x) = 2x − 2 → k = f′(2) = 2
  3. 10 = 2 · 2 + d → d = 6
  4. t: y = 2x + 6

Die Ableitungen verraten alles über den Graphen. f′ sagt, ob f steigt oder fällt. f″ sagt, wie f gekrümmt ist. Das ist der ganze Trick dieses Kapitels.

1. Monotonie

Definition

f heißt in einem Intervall I streng monoton steigend, wenn für alle x1, x2 ∈ I gilt: x1 < x2 ⇒ f(x1) < f(x2). Analog streng monoton fallend: x1 < x2 ⇒ f(x1) > f(x2). (Mit ≤ bzw. ≥ heißt es nur „monoton steigend/fallend“.)

Monotoniesatz

Ist f eine Polynomfunktion und I ein Intervall, dann gilt:

(1) f′(x) > 0 für alle inneren Stellen x von I ⇒ f ist in I streng monoton steigend.
(2) f′(x) < 0 für alle inneren Stellen x von I ⇒ f ist in I streng monoton fallend.

Umgekehrt gilt das nicht ganz: f(x) = x³ ist überall streng monoton steigend, obwohl f′(0) = 0.

2. Extremstellen

Definition

p heißt lokale Maximumstelle von f, wenn es ein Intervall um p gibt, in dem f(x) ≤ f(p) für alle x gilt. Der Punkt H = (p | f(p)) heißt Hochpunkt. Analog: lokale Minimumstelle, Tiefpunkt T. Gilt die Ungleichung im ganzen Definitionsbereich, ist es eine globale Extremstelle.

Notwendige Bedingung

Ist p eine lokale Extremstelle (innere Stelle) der Polynomfunktion f, dann gilt f′(p) = 0. Die Tangente ist dort waagrecht.

„Notwendig“ heißt: Ohne f′(p) = 0 geht es nicht. Aber es reicht nicht! Die Lösungen von f′(x) = 0 sind nur Kandidaten. Es könnte auch eine Terrassenstelle sein (wie x³ bei 0).

Hinreichend · Variante A: Vorzeichenwechsel

Ändert f′ bei p das Vorzeichen (f ändert sein Monotonieverhalten), dann ist p eine lokale Extremstelle:

  • f′ wechselt von + nach − (erst steigend, dann fallend) → Maximum
  • f′ wechselt von − nach + → Minimum
  • kein Vorzeichenwechsel → keine Extremstelle (Terrassenstelle)
Hinreichend · Variante B: zweite Ableitung

(1) f′(p) = 0 ∧ f″(p) < 0 ⇒ p ist lokale Maximumstelle (Graph rechtsgekrümmt, ∩)
(2) f′(p) = 0 ∧ f″(p) > 0 ⇒ p ist lokale Minimumstelle (Graph linksgekrümmt, ∪)

Rotstift · Mitschrift 12.10.

Bei (2) steht in deiner Mitschrift „f″(p) ≥ 0“. Richtig ist > 0, streng! Ist f″(p) = 0, sagt der Test gar nichts. Dann musst du mit dem Vorzeichenwechsel von f′ (Variante A) prüfen. Beispiel: f(x) = x4 hat bei 0 ein Minimum, f(x) = x³ hat bei 0 eine Terrassenstelle, aber beide Male ist f″(0) = 0.

Eselsbrücke

f″ negativ → Hochpunkt (traurig ∩), f″ positiv → Tiefpunkt (fröhlich ∪). Das Vorzeichen ist „verkehrt“ zu dem, was man erwarten würde.

Beispiel komplett 3.11 a · 5.10.

  1. f′(x) = 6x² − 6x − 12
  2. f′(x) = 0 → x² − x − 2 = 0 → x = −1, x = 2 (Kandidaten)
  3. Testwerte: f′(−2) = 24 > 0, f′(0) = −12 < 0, f′(3) = 24 > 0
  4. Bei −1 wechselt f′ von + nach − → Maximum. Bei 2 von − nach + → Minimum.
  5. H = (−1 | f(−1)) = (−1 | 8), T = (2 | f(2)) = (2 | −19)
  6. Monotonie: streng monoton steigend in (−∞; −1], fallend in [−1; 2], steigend in [2; ∞)
Schreibweise Monotoniebereiche

Wie im Buch: Die Extremstellen gehören zu beiden Bereichen dazu, also eckige Klammern [−1; 2]. Bei ±∞ immer runde Klammer: (−∞; −1].

Extremstellen in abgeschlossenen Intervallen (Randextrema)

Ist f nur auf [a; b] definiert, können die größten/kleinsten Werte auch am Rand liegen, wo f′ ≠ 0 sein kann. Darum: Funktionswerte an allen Kandidaten UND an beiden Rändern vergleichen.

Beispiel

4. Wendestellen & Sattelstellen

Definition

Eine Stelle p heißt Wendestelle von f, wenn sich an der Stelle p das Krümmungsverhalten von f ändert. W = (p | f(p)) heißt Wendepunkt, die Tangente in p heißt Wendetangente.

Satz

f″(p) = 0 ∧ f‴(p) ≠ 0  ⇒  p ist Wendestelle von f

(f″(p) = 0 allein ist nur notwendig.) Außerdem: Eine Wendestelle von f ist eine lokale Extremstelle von f′. Dort ist f also am steilsten (stärkste Steigung oder stärkstes Gefälle).

Sattelpunkt (Terrassenpunkt)

Ein Wendepunkt mit waagrechter Tangente: f′(p) = 0 ∧ f″(p) = 0 ∧ f‴(p) ≠ 0. Der Graph macht dort eine „Stufe“, steigt (oder fällt) aber vorher und nachher weiter.

Rotstift · SA 2025, Bsp. 15 a

„Weise rechnerisch nach, dass 2 die einzige Wendestelle ist“: f″(x) = 0 lösen allein bringt nur einen halben Punkt. Immer dazuschreiben: f‴(2) = 23 ≠ 0. Und begründen, warum die zweite Lösung x = 6 nicht zählt (nicht im offenen Intervall (0; 6)).

Kontext-Signalwörter für Wendestellen: „stärkstes Gefälle“, „größte Steigung“, „am schnellsten wachsen“, „größte Geschwindigkeit“ (wenn s gegeben ist), „ab wann wächst es langsamer“.

5. Graph-Explorer: f, f′ und f″ nebeneinander

Fahr mit dem Regler (oder Finger/Maus) über die Graphen. Achte darauf: Wo f′ die x-Achse schneidet, hat f einen Hoch- oder Tiefpunkt. Wo f″ die x-Achse schneidet, hat f einen Wendepunkt, und f′ hat dort sein Extremum.

6. Symmetrie, Verhalten im Unendlichen, typische Formen

Definition

Eine reelle Funktion f: A → ℝ heißt
• gerade, wenn für alle x ∈ A gilt: f(−x) = f(x). Der Graph ist symmetrisch zur y-Achse.
• ungerade, wenn für alle x ∈ A gilt: f(−x) = −f(x). Der Graph ist symmetrisch zum Ursprung (punktsymmetrisch).

Für Polynome

Eine Polynomfunktion ist gerade, wenn nur gerade Hochzahlen vorkommen (die Koeffizienten der ungeraden Potenzen sind 0), z. B. 3x4 + 2x² − 5 (die Konstante zählt als x0, also gerade). Sie ist ungerade, wenn nur ungerade Hochzahlen vorkommen, z. B. 3x³ + 2x (keine Konstante!). x³ + x² ist weder noch.

Verhalten für x → ±∞

Für große |x| bestimmt nur der Term mit der höchsten Hochzahl anxn, wohin der Graph geht:

B1 · Differenzenquotient einer linearen Funktion ist k

f(b) − f(a)b − a = (kb + d) − (ka + d)b − a = k(b − a)b − a = k  ∎

B2 · Konstante: f(x) = c ⇒ f′(x) = 0

f′(x) = limz→x f(z) − f(x)z − x = limz→x c − cz − x = limz→x 0 = 0  ∎

B3 · f(x) = x ⇒ f′(x) = 1 (allgemeiner: a·x ⇒ a)

f′(x) = limz→x z − xz − x = limz→x 1 = 1     limz→x az − axz − x = limz→x a(z − x)z − x = a  ∎

B4 · f(x) = a·x² ⇒ f′(x) = 2a·x

f′(x) = limz→x az² − ax²z − x = limz→x a(z − x)(z + x)z − x = limz→x a(z + x) = a(x + x) = 2ax  ∎

B5 · Potenzregel: f(x) = xⁿ ⇒ f′(x) = n·xⁿ⁻¹

Mit der Regel von Horner (a = z, b = x):

f′(x) = limz→x zn − xnz − x = limz→x (z − x)(zn−1 + zn−2x + … + xn−1)z − x
= limz→x (zn−1 + zn−2x + … + xn−1) = xn−1 + xn−1 + … + xn−1 = n · xn−1  ∎

In der Klammer stehen n Summanden; jeder wird für z = x zu xn−1.

B6 · Faktor- und Summenregel

limz→x c·g(z) − c·g(x)z − x = c · limz→x g(z) − g(x)z − x = c · g′(x)

limz→x [g(z) + h(z)] − [g(x) + h(x)]z − x = limz→x g(z) − g(x)z − x + limz→x h(z) − h(x)z − x = g′(x) + h′(x)  ∎

B7 · Regel von Horner

(a − b)(an−1 + an−2b + … + abn−2 + bn−1)
= an + an−1b + … + a²bn−2 + abn−1 − an−1b − an−2b² − … − abn−1 − bn = an − bn  ∎

Beim Ausmultiplizieren heben sich alle mittleren Terme paarweise weg; nur der erste und der letzte bleiben.

B8 · Abspalten eines Linearfaktors: f(x) = (x − x₀)·g(x)

Sei f(x) = anxn + … + a1x + a0 und f(x0) = 0. Dann

f(x) = f(x) − f(x0) = an(xn − x0n) + an−1(xn−1 − x0n−1) + … + a1(x − x0)

Auf jede Klammer die Regel von Horner anwenden: Jede enthält den Faktor (x − x0). Herausheben ergibt f(x) = (x − x0)·(anxn−1 + …) = (x − x0)·g(x). Wegen an ≠ 0 hat g den Grad n − 1. ∎

B9 · Eine Gleichung vom Grad n hat höchstens n Lösungen

Hat f die Lösungen x1, …, xk, kann man (B8) nacheinander die Linearfaktoren abspalten. Jedes Mal sinkt der Grad um 1. Nach n Schritten wäre f(x) = an(x − x1)…(x − xn). Wäre x* eine weitere Lösung, müsste nach dem Produkt-Null-Satz ein Faktor null sein (an ≠ 0), also x* = xi für ein i. Also gibt es höchstens n verschiedene Lösungen. ∎

B10 · Warum f′(p) = 0 bei einem Extremum (notwendige Bedingung)

Sei p eine lokale Maximumstelle, also f(z) ≤ f(p) für z nahe p. Für z > p ist der Zähler f(z) − f(p) ≤ 0, der Nenner positiv, also f(z) − f(p)z − p ≤ 0. Für z < p ist der Nenner negativ, also der Quotient ≥ 0. Der Grenzwert f′(p) muss also gleichzeitig ≤ 0 und ≥ 0 sein: f′(p) = 0. ∎

  • x(x-2) versteht der TI als Funktion x an der Stelle x−2. Immer x*(x-2).
  • Minus als Vorzeichen: Am Computer reicht -; der Taschenrechner hat eine eigene (−)-Taste.
  • Bei Systemen: alle Unbekannten in { }, Gleichungen mit and verbinden.
  • Hat a schon einen Wert (z. B. aus der Aufgabe davor), kommt Unsinn heraus. Dann delVar.
  • Grad-Modus kontrollieren, bevor du Winkel rechnest.
  • Ins Heft immer die Gleichung schreiben, die du gelöst hast, nicht nur den Befehl.
