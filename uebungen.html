Kapitel 1.1 · Buch S. 8

Herausheben & Produkt-Null-Satz

Rezept: Alles auf eine Seite (= 0). Die kleinste x-Potenz (oder eine gemeinsame Klammer) herausheben. Jeden Faktor null setzen. Nie durch x dividieren.
Buch 1.07HandSA-typisch
Jemand löst die Gleichung x³ − 4x² − 5x = 0 so: „| : x“ → x² − 4x − 5 = 0 → x = −1 ∨ x = 5. Die Lösung x = 0 ist verloren gegangen. Wo liegt der Fehler? Gib die richtige Lösungsmenge an.
Ergebnis

Durch x darf man nur dividieren, wenn x ≠ 0 ist. Dabei geht die Lösung 0 verloren. L = {−1; 0; 5}

Lösungsweg Schritt für Schritt
Die Idee

Division durch 0 ist verboten. Wer durch x teilt, nimmt stillschweigend an, dass x ≠ 0 ist, und wirft damit die Lösung x = 0 weg.

Schritt für Schritt
  1. Statt zu dividieren: x herausheben → x·(x² − 4x − 5) = 0
  2. Produkt-Null-Satz: x = 0 oder x² − 4x − 5 = 0Ein Produkt ist 0, wenn mindestens ein Faktor 0 ist.
  3. Kleine Lösungsformel mit p = −4, q = −5: x = 2 ± √(4 + 5) = 2 ± 3 → x = 5 oder x = −1
  4. L = {−1; 0; 5}

Kontrolle am TI: solve(x^3-4*x^2-5*x=0,x) → x=−1 or x=0 or x=5

Ergebnis

Durch x darf man nur dividieren, wenn x ≠ 0 ist. Dabei geht die Lösung 0 verloren. L = {−1; 0; 5}

Kapitel 1.1 · Buch S. 8–9

Substitution

Rezept: Kommen nur x⁴ und x² vor (oder x⁶ und x³)? Setze u = x² (bzw. u = x³). Löse die quadratische Gleichung in u. Rücksubstitution: x² = u → bei u > 0 zwei Lösungen ±√u, bei u < 0 keine. x³ = u → genau eine Lösung ∛u (auch für negative u).
Buch 1.13 a, bHand
Ermittle alle reellen Lösungen durch Substitution: a) x⁴ − 20x² + 64 = 0   b) x⁴ − 5x² + 6 = 0
Ergebnis

a) L = {−4; −2; 2; 4}   b) L = {−√3; −√2; √2; √3}

Lösungsweg Schritt für Schritt
Die Idee

Nur x⁴ und x² → u = x² setzen. Dann ist es eine normale quadratische Gleichung. Am Ende zurück zu x!

Schritt für Schritt
  1. a) u = x²: u² − 20u + 64 = 0 → u = 10 ± √(100 − 64) = 10 ± 6 → u = 16 oder u = 4.
  2. Rücksubstitution: x² = 16 → x = ±4; x² = 4 → x = ±2.Gefragt ist x, nicht u. Darum nie bei den u-Werten aufhören.
  3. b) u² − 5u + 6 = 0 → u = 2,5 ± √(6,25 − 6) = 2,5 ± 0,5 → u = 3 oder u = 2.
  4. x² = 3 → x = ±√3; x² = 2 → x = ±√2.

TI: solve(x^4-5*x^2+6=0,x) → x = ±1.414…, ±1.732… (das sind √2 und √3)

Ergebnis

a) L = {−4; −2; 2; 4}   b) L = {−√3; −√2; √2; √3}

Die Idee

Kapitel 1.1–1.2 · Buch S. 9–13

Linearfaktoren & Regel von Horner

Rezept: Eine Lösung x₀ erraten (Teiler des konstanten Glieds probieren: ±1, ±2, ±3 …). Durch (x − x₀) dividieren (Polynomdivision). Den Rest (Grad 2) mit der Lösungsformel lösen. Am TI geht beides auf einmal: factor(…).
Buch 1.19 a, bHand
Zeige mithilfe der Regel von Horner, dass die Gleichung nur eine Lösung in ℝ besitzt: a) x³ − 27 = 0   b) x³ − 64 = 0
Ergebnis

a) einzige Lösung x = 3   b) einzige Lösung x = 4

Lösungsweg Schritt für Schritt
Die Idee

Horner für n = 3: a³ − b³ = (a − b)(a² + ab + b²). Dann zeigen, dass der quadratische Faktor keine Lösung hat.

Schritt für Schritt
  1. a) x³ − 27 = x³ − 3³ = (x − 3)(x² + 3x + 9) = 0
  2. x − 3 = 0 → x = 3.
  3. x² + 3x + 9 = 0: Diskriminante (p/2)² − q = 2,25 − 9 < 0 → keine reelle Lösung.Darum ist 3 die einzige Lösung. Genau dieses Argument will die Aufgabe sehen.
  4. b) x³ − 4³ = (x − 4)(x² + 4x + 16). x² + 4x + 16: 4 − 16 < 0 → keine Lösung. Einzige Lösung x = 4.
Ergebnis

a) einzige Lösung x = 3   b) einzige Lösung x = 4
